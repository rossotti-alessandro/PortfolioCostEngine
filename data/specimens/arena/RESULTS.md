## How each workflow works

- **App before SC-5.8**: The app's per-document-type parsers. Precise where they know the layout, blind elsewhere.
- **App after SC-5.8**: Parsers plus the layout-aware finder, cross-checked; doubtful values go to review.
- **Finder + verify**: Every figure on the page linked to its row label and column header; Tesseract re-reads each value.
- **Finder + table layout**: As above, with table regions from PP-DocLayoutV3; RapidOCR re-reads each value.
- **Vision reader**: PaddleOCR-VL reads table rows; each value is anchored to a text-layer box (no box, no figure).
- **Agentic review (Qwen3-4B-Instruct-2507)**: Finder + verify, then a local language model checks each candidate with tools (second OCR, table row) and keeps, drops or flags it. It cannot write a number.
- **Agent flags only (Qwen3-4B-Instruct-2507)**: The same agent run, but a 'not a fee' answer only sends the figure to review instead of dropping it: the model can never remove a figure on its own.
- **Agent flags, zeros kept (Qwen3-4B-Instruct-2507)**: Agent flags only, and its opinion on zero charges is ignored (it mistook them for 'no fee').
- **Revalidation: arithmetic only**: Finder + verify, then page arithmetic only: rows that add up to the printed total, and a KID amount that matches its % on 10 000, confirm each other. No model; what the app runs with PCE_REVALIDATE=1.
- **Revalidation: more readers**: Finder + verify; a value whose reading is in doubt goes to RapidOCR, then docTR, then the vision reader's table row, stopping at the first that reads the same number there.
- **Revalidation: readers + arithmetic**: As above, plus page arithmetic: rows that add up to the printed total, and a KID amount that matches its % on 10 000, confirm each other.
- **Revalidation: full graph**: As above, plus the local language model as critic (Qwen3-4B): it may only flag a value, never confirm, drop or change one.
- **Revalidation: full, zeros kept**: The full graph, with the critic's opinion on zero charges ignored.
- **Two readers must agree**: Finder + verify and the vision reader read the page independently; a figure the vision reader did not also see (same value, same spot) goes to review. Vision ran on 23 pages.
- **Two readers, nothing dropped**: As above, plus figures only the vision reader found, always sent to review.
