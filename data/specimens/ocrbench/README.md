# Local OCR, layout, table and VLM benchmark (SC-5.6)

Which locally runnable models read fees from bank and fund documents best, how fast, at what
cost, and how to combine them. Everything runs on the analyst's machine: no page leaves it.
The pages are public documents from the specimen corpus (`data/reference/specimen_corpus.csv`),
never client documents.

Results: [SCORES.md](SCORES.md) (regenerated by `score.py`). The interactive lab (page images with
every engine's boxes, tables and fees) is built locally by `lab.py`; it holds third-party page
images, so it lives in `var/` and is not committed.

## What is in here

| File | Role |
|---|---|
| `select_pages.py` | Picks a stratified page set (18 document families x EN/DE/FR/IT), renders pages at 144 dpi, makes simulated scans. Writes `pages.json`. |
| `groundtruth.txt` | Hand-checked fee figures per page (label, value as printed, layout element: T table, K key-value, N text, F footnote). Read from the rendered page, not from the text layer. |
| `gt_build.py` | Turns `groundtruth.txt` into `groundtruth.json` and adds each value's box from the PDF text layer. |
| `adapters.py` | One function per engine, same output shape: text, word/line boxes, layout regions, tables, fees. |
| `run.py` | Runs one engine over the pages in its own process (so peak RAM is that engine's). |
| `fees.py` | Number normalisation and the shared fee extractors (line rule and table-aware rule). |
| `score.py` | Scores every engine against the ground truth. Writes `SCORES.md` and `var/ocrbench/scores.json`. |
| `hybrid.py` | Builds hybrid pipelines from stored outputs (no new model calls) and the consensus/review numbers. |
| `lab.py`, `lab_template.html` | Builds the lab viewer in `var/ocrbench/lab/`. |
| `models.json` | Facts per engine (size, licence, what it returns) and the models looked at but not run, with the reason. |
| `vlm_core.json` | The 23-page core set the slow VLMs run on first, and the 8-page `mini` set for the slowest ones. |
| `app_run.py` | Runs the FeeLens upload pipeline (`pce.extraction.parsers.extract`) on every page as one more engine. Backend env. |
| `app_e2e.py` | Runs the SYNTHETIC prospects end to end through the app and the accuracy protocol, for the lab's "App end to end" view. Backend env. |

## Run it

```bash
# one-time: a separate venv so heavy ML packages never touch the backend's lock file
uv venv -p 3.12 var/ocrbench/.venv
uv pip install -p var/ocrbench/.venv torch torchvision --index-url https://download.pytorch.org/whl/cpu
uv pip install -p var/ocrbench/.venv "transformers>=5.2" accelerate pillow pypdfium2 pdfplumber psutil \
    timm einops huggingface_hub rapidocr onnxruntime python-doctr pytesseract docling doclayout-yolo
PY=var/ocrbench/.venv/bin/python

python3 data/specimens/tools/fetch.py                     # corpus PDFs -> var/specimens
$PY data/specimens/ocrbench/select_pages.py               # pages -> var/ocrbench/pages
$PY data/specimens/ocrbench/gt_build.py                   # groundtruth.txt -> groundtruth.json
for e in pdfplumber tesseract rapidocr doctr heron ppdoclayout3 doclayout_yolo tatr docling layoutlm_docqa; do
  $PY data/specimens/ocrbench/run.py $e; done
for e in paddleocr_vl lighton_ocr glm_ocr granite_docling qwen3vl got_ocr florence2; do
  $PY data/specimens/ocrbench/run.py $e --core; done       # add no flag for all pages (hours on CPU)
(cd backend && OMP_THREAD_LIMIT=1 uv run python ../data/specimens/ocrbench/app_run.py \
  && OMP_THREAD_LIMIT=1 uv run python ../data/specimens/ocrbench/app_e2e.py)   # the app as an engine
$PY data/specimens/ocrbench/hybrid.py --vlm paddleocr_vl
$PY data/specimens/ocrbench/score.py
$PY data/specimens/ocrbench/lab.py && (cd var/ocrbench/lab && python3 -m http.server 8765)
```

Weights download once from Hugging Face into the normal cache (about 20 GB for all engines).

## Rules this benchmark keeps

- **Local only.** Models run on CPU here; nothing is sent to an external API.
- **No AGPL in the product.** `doclayout_yolo` (AGPL-3.0 package) is measured for comparison only and
  flagged in every table. PyMuPDF is not installed (checked).
- **Never invent fees.** The ground truth holds only figures printed on the page; four pages hold none and
  measure false positives. Engines that return no box get none (no guessed coordinates).
- **Missing is not zero.** A page an engine did not run is left out of its score, never counted as 0 or 100.
- **Simulated scans are labelled** `SIMULATED SCAN` in the lab and `variant: scan-sim` in `pages.json`.

## How to read the scores

- *Label + value same row*: the value and at least half of its label words appear on one line or table
  row of the output. This is what a fee parser needs; the main score.
- *In a table row*: the same, but only inside tables the engine itself produced (structure, not text).
- *Value boxed*: a box that holds the number and covers the printed value, at most about three lines high.
- *Table ROI hit*: fees printed in tables fall inside a table region the engine detected.
- *Extract* (line rule): the shared extractor keeps numbers on a line that has a fee word.
  *Table-aware*: also keeps every rate or amount inside a table whose cells or heading mention a fee.
- *s/page*: median wall time after model load, 4 CPU cores (Xeon with AMX), no GPU.

Known limits: 54 pages with 813 fee figures is enough to rank engines, not to quote a precise accuracy;
labels are short forms of what is printed; one annotator (Claude), spot-checked against the rendered page.
