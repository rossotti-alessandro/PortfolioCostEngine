Main score: fee figure read with its label on the same row, the input a fee parser needs. Click a column to sort. All runs on 4 CPU cores, no GPU.

What each column means
  • Label + value same row: share of hand-checked fee figures whose value and at least half of its label words appear on one line or table row of the engine's output.
  • Values read: the number appears anywhere in the output (reading only, no structure).
  • Value boxed: the engine gives a box that holds the number and covers the printed value (word or line level, at most ~3 lines high).
  • Table ROI hit: for fees printed in tables, the engine marked a table region covering them.
  • Extract precision / recall: the same simple fee-line extractor runs on every engine's text (or the engine's own fee list). Precision counts wrong numbers taken as fees, including on pages with no fees.
  • Text F1: word overlap with the PDF's own text layer on born-digital pages.
  • s/page: median seconds per page after the model is loaded.
