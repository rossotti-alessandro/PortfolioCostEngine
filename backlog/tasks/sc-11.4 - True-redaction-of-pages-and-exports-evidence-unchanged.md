> **One-liner**: Produce redacted copies of pages and exports where personal data is removed for good, while every fee keeps its page and box.

## Description

### Context

Exports and support bundles would carry names, IBANs and account numbers. A black rectangle drawn over a PDF leaves the text underneath, which is not redaction.

### User Flow Impact

A 'redacted copy' download; client report and exports use it by default.

### Performance / Efficiency Impact

Rasterising a page at 150 dpi takes ~100-300 ms; only on export.

### Proposed Approach

1. Render page with pypdfium2, paint boxes for SC-11.3 spans (word boxes from pdfplumber)
2. Rebuild a PDF from images; optional OCR text layer via the OCRmyPDF CLI
3. Same page size so evidence boxes stay valid
4. Leak test: extract text from the output and run `detect` again: zero spans

### Risks & Follow-ups

No PyMuPDF (AGPL). Redaction of scanned pages depends on OCR word boxes. Plan: "FeeLens: going live with client data" (project doc, 2026-11-12).

## Acceptance Criteria

- [ ] #1 Redacted output re-scanned with `detect` and plain text extraction returns no synthetic PII
- [ ] #2 Fee evidence boxes for the same page match before and after redaction (regression guard)
