> **One-liner**: Add names, addresses and contextual personal data to the detector with a local GLiNER2-PII model (Apache-2.0) and a local language-model checker that can only add redactions or ask a human.

## Description

### Context

Rules (SC-11.3) cannot find names or addresses. The revalidation thread is adding a local language model.

### User Flow Impact

Uncertain spans show up as review points for the analyst.

### Performance / Efficiency Impact

GLiNER2-PII ~300M params on CPU: to measure per page; run only on exits.

### Proposed Approach

1. Optional extra with GLiNER2-PII, labels per firm
2. Checker prompt with page crop + neighbours; may only add spans or escalate
3. Leak check: rules + model rerun on output, canary values in tests
4. Score on a synthetic PII set

### Risks & Follow-ups

Model licence check before adding; local only (ADR 0004). Coordinate with 'Add agentic revalidation of extracted values'. Plan: "FeeLens: going live with client data" (project doc, 2026-11-12).

## Acceptance Criteria

- [x] #1 On the synthetic PII set, recall for names and addresses is reported and every rule-found span stays redacted after the checker
- [x] #2 The checker cannot remove a rule-found span (regression guard)

## Implementation Notes

- Owned paths differ from the original plan: the model and checker live in `pce/pii_names.py`, and
  `pce/pii.py` gains `detect_all`, `redact`, `names_available` and `LeakError`. `backend/pyproject.toml`
  and `uv.lock` are shared contracts: this PR adds the optional extra `pii` (gliner2[local]==2.2.0, adds
  gliner2 and peft to the lock; torch and transformers were already locked through Docling). Licence
  change: needs Ale's approval (AGENTS.md rule 9).
- Model: fastino/gliner2-privacy-filter-PII-multi (Apache-2.0), revision pinned, offline load only.
- The "agentic checker" is deterministic and narrow (coordinator, 2026-11-26: the on-demand expert agent
  is SC-5.24): it can only add spans (holder labels, salutations, repeats, postcode lines) and reports
  model proposals between 0.3 and 0.5 as `uncertain`. No local language model: the rule-plus-model
  pipeline already reaches 99% on the set, and an LLM step would add minutes per page on CPU.
- `redact` is the agreed entry point for SC-5.24 (expert agent) before any hosted call, with
  `names_available()` as its precondition.
