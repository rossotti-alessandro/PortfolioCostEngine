> **One-liner**: One-command install of FeeLens on a Safe Capital machine with encrypted storage, daily backup, tested restore and automatic deletion after the retention period.

## Description

### Context

The only deployment is the Render demo with an ephemeral disk, unsuitable for client data.

### User Flow Impact

Analysts open FeeLens on an office machine; files survive restarts.

### Performance / Efficiency Impact

No measurable impact.

### Proposed Approach

1. `deployment/local/compose.yaml` using the existing Dockerfile, data on a named volume
2. Guide for disk encryption (BitLocker/FileVault/LUKS)
3. `backup.sh` + `restore.sh`, encrypted with age
4. Retention: delete prospects older than PCE_RETENTION_DAYS, record the deletion

### Risks & Follow-ups

Retention deletion touches the DB: coordinate with SC-11.2. Plan: "FeeLens: going live with client data" (project doc, 2026-11-12).
