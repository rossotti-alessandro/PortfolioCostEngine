> **One-liner**: Each person signs in with their own account via Microsoft 365 (OIDC) with MFA, or a local account with passkey, and gets analyst, senior, admin or auditor rights.

## Description

### Context

One env-seeded admin (PR #9). No way to tell who did what; no MFA; revoke means rotating the key.

### User Flow Impact

Sign in with Microsoft button; admin page lists users.

### Performance / Efficiency Impact

Server-side session lookup per request; negligible.

### Proposed Approach

1. ADR for OIDC (Authlib, BSD) and session store
2. User table per tenant, roles
3. Server-side sessions with idle timeout and revoke
4. Keep env admin as break-glass

### Risks & Follow-ups

Auth change: needs Ale's per-PR approval (rule 9). DB schema is a shared contract. Plan: "FeeLens: going live with client data" (project doc, 2026-11-12).

## Acceptance Criteria

- [x] #1 A user of tenant A cannot read tenant B, and a revoked session is refused on the next request
- [x] #2 Existing env admin sign-in keeps working as break-glass (regression guard)

## Implementation Notes

Scope changed from OIDC to local accounts with authenticator TOTP so the pilot does not depend on Microsoft 365 (READINESS D3 still open); OIDC stays with SC-11.2. Owned paths added: backend/src/pce/users.py, auth.py, security.py, db.py (UserAccount), frontend Login.tsx, Users.tsx, Shell.tsx, main.tsx, lib/api.ts, lib/it.ts, tests/test_accounts.py.

## Outcome

Named accounts in the database with roles, admin flag, scrypt hash and per-account session_version. Admins create, reset (new one-time password, authenticator cleared), disable and sign out users of their own firm from the Users page or `python -m pce.users`. First sign-in forces a new password and, with PCE_REQUIRE_MFA=1, an authenticator app (RFC 6238, replay refused). Env admin kept as break-glass. Tests: tests/test_accounts.py (6), existing security tests green. AC #1: other-tenant actions return 404 and a reset/disabled account's session is refused on the next request (test_admin_manages_only_own_firm_and_actions_end_sessions). AC #2: env admin sign-in unchanged (test_security).
